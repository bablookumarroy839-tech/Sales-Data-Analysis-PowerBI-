# Sales & Data Analysis — Power BI Dashboard

## 📊 Project Overview

This project presents an interactive **Sales & Data Analysis Dashboard** built using Microsoft Power BI.

The dashboard transforms raw sales data into meaningful business insights, helping analyze **sales performance, profitability, customer segments, product categories, regions, and trends over time**.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query** — Data Cleaning & Transformation
* **DAX** — Calculated Measures & KPIs
* **Data Visualization**
* **Business Intelligence**

## 📈 Dashboard Highlights

The dashboard provides an interactive view of:

* Total Sales
* Total Profit
* Total Orders
* Sales & Profit trends
* Category-wise performance
* Region-wise performance
* Segment-wise analysis
* Product-level performance
* Time-based sales analysis
* Interactive filters and slicers

## 💡 Key Business Questions

The dashboard helps answer questions such as:

1. What is the overall sales and profit performance?
2. Which product categories generate the highest sales?
3. Which regions contribute the most revenue?
4. Which customer segments are most profitable?
5. Which products perform best and worst?
6. How does sales performance change over time?
7. Where are potential areas for improving profitability?
